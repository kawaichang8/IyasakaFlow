# CRMアプリ - ワイヤーフレーム

## 📱 画面レイアウト設計

### デザイン原則

- **シンプル**: 初心者でも直感的に操作できる
- **効率的**: プロの営業マンが素早く作業できる
- **一貫性**: 全画面で統一されたUI/UX
- **レスポンシブ**: PC、タブレット、スマホに対応

---

│  │ リード    │ │ 提案      │ │ 交渉      │ │ 成約 ││
│  ├──────────┤ ├──────────┤ ├──────────┤ ├─────┤│

│  │          │ │          │ │          │ │     ││
│  │ [カード] │ │          │ │          │ │     ││

## 📱 モバイル版（簡易版）

モバイル版は主要機能に絞り込み：

1. **ダッシュボード**: サマリーとタスク
2. **顧客一覧**: カード形式のみ
3. **顧客詳細**: 基本情報と活動履歴
4. **タスク管理**: シンプルなリスト
5. **パイプライン**: 横スクロール可能なKanban

---

## 🎨 デザインシステム

### カラーパレット
- **プライマリ**: 青系（信頼感）
- **セカンダリ**: 緑系（成功・成約）
- **アクセント**: オレンジ系（注意・警告）
- **背景**: 白・ライトグレー

### タイポグラフィ
- **見出し**: 太字、大きめのフォント
- **本文**: 読みやすいサイズ
- **ラベル**: 小さめ、色分け

### コンポーネント
- **ボタン**: 角丸、明確なCTA
- **カード**: 影付き、ホバー効果
- **フォーム**: 明確なラベル、エラー表示
